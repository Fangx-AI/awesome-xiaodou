## 第一次怎么试

1. 选一个有权限使用的场景，把模板中的方括号替换为你的信息。
2. 让小豆说明它能执行哪些步骤、需要哪些连接，以及是否已经创建任务。
3. 先做一次小范围尝试，核对通知、数据和实际结果；持续任务还需确认修改和停止方式。
4. 把应用版本、测试日期、成功或失败现象记录下来，欢迎通过 Issue 补充。

**怎么判断收录内容可靠？**

- **官方说明**：有可直接查看的官方功能说明；不代表本项目完成实测。
- **媒体报道 / 社区文章**：原文描述过该场景；保留原链接和日期。
- **社区实测**：贡献者提供版本、步骤和结果证据后标记；说明适用范围。
- **创意待验证**：仅有想法，放入 Issue 讨论，验证或补充依据后再进目录。

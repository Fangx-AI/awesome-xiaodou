# 使用小豆 Skill

## 小豆独立 App

1. 打开[8 条常用指令](../prompts/xiaodou-quick-pack.txt)或[完整 43 条](../prompts/xiaodou-paste-pack.txt)，点 GitHub 文件工具栏中的复制按钮，或打开 Raw 后全选复制。
2. 在小豆中新开一个对话，粘贴发送选好的提示词包。
3. 在同一个对话里说「帮我做个减肥计划」「今天的收藏里有什么店」或「看菜单」。

只想办一件事时，可以复制[单条提示词](../skills/xiaodou-skill/references/prompts.md)。整包粘贴在当前对话生效。小豆独立 App 的第三方技能导入入口仍待核实。

## 豆包工作 / 支持 Agent Skills 的客户端

1. [下载 xiaodou-skill.zip](https://github.com/Fangx-AI/awesome-xiaodou/releases/latest/download/xiaodou-skill.zip)。
2. 解压，保留 `xiaodou-skill` 文件夹及其 `references`。在支持技能导入的客户端选择该技能文件夹，或按客户端要求上传技能。豆包工作的入口在「技能」中的本地导入。
3. 在已启用技能的对话中说「用小豆 Skill 帮我做个减肥计划」，或在技能选择器中选择它。

包内只有说明和提示词。不同客户端的导入格式和权限以实际界面为准。本版已检查 ZIP 结构，豆包工作及小豆客户端导入尚未实测。

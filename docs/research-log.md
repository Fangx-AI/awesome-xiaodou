- 本次部分网页直连读取失败，但搜索索引返回了正文或较完整段落；已按可见内容归纳，没有声称观看配图、录屏或完整视频。

- GitHub 资料由 API 直接读取。不是搜索结果里所有带“小豆”的仓库都属于该产品，支付平台、阅读器等同名项目已排除。
- 53AI 文章只核对到开头部分，未据标题的“全功能”或“首测”扩写能力清单。
- 没有登入各平台做站内穷尽检索。这是一次公开网络范围的广泛搜集，**不代表覆盖全网全部内容**。

## 去重与收录规则

1. 优先原帖、原作者文章、授权转载，再使用聚合页面寻找线索。
2. 同一官方演示或同一作者稿件的转载不增加独立案例数。
3. 以“输入、动作、结果”不同划分玩法，重复报道补充到已有条目。
4. 原作者经验、媒体功能描述、内置模板、仓库真机实测分开标注。
5. 指令模板由本项目重新编写；保留来源，不将模板冒充作者原话。

# 普通小豆与皇帝模式 · 两种改案

自己试时，挑下面一套题，在同一台手机的小豆 App 里开两个新对话。一组用普通小豆，一组用皇帝模式。有人协助观察时，先和对方约定题目和先后顺序；不同参与者交替先试的模式。两组使用相同的小豆版本、权限和观察上限。

皇帝模式在[通用开局](../../README.md#一句话在小豆里开始)末尾加上第一条任务，一起发送。普通小豆只发任务。每组按顺序发送同一套消息，每次等实际回复后再发下一条。两个案例使用虚构资料，避免发送私人的日程、名单或联系方式。

## 阅读计划改标准

**开局**

```text
我想养成每天读一点书的习惯。今晚有五分钟，饭后能读电子书。先约定读完一页才算完成，给我今天能开始的一步。
```

**报实际进度**

```text
本周周二、周四各读完一页，已经完成两次。昨晚只把电子书翻到原来的位置，一页也没读完。请记下这三次的实际情况。
```

**改计划**

```text
从今天开始我只有午饭后三分钟，想改成读完一段就算完成。请按现在的条件告诉我下一步，并回顾本周进度。
```

## 活动物料改预算

**开局**

```text
我在安排周六的社区读书会，场地已确认，活动公告草稿已完成。今晚有十分钟，原预算 120 元，只要排一下签到物料的下一步，先别采购或发公告。
```

**报实际进度**

```text
我已做完一张签到表。公告仍是草稿，场地照旧。还没买物料，先帮我记一下进度。
```

**改计划**

```text
签到物料预算改成 60 元，人数不变。现场已经有纸和笔。请只改物料安排，保留已完成的内容，给我下一步。先别买东西或发公告。
```

**核对续办状态**

```text
我现在回来接着办。请核对场地、公告、签到表和预算分别到哪了，给我一个可以继续做的动作。
```

## 怎样评分

- **首步**。阅读给出饭后五分钟能读的一步，并沿用完成一页的标准。读书会给出十分钟内可做的物料准备动作和完成标准。
- **保留进度**。阅读保留周二和周四两次完成，昨晚只有准备动作。读书会保留确认的场地和完成的签到表，公告仍是草稿。
- **只改受影响的事**。阅读的新口径从今天起算。读书会只改物料，沿用人数和现有纸笔。
- **改后还能继续**。阅读给出午饭后三分钟内可做的一步。读书会给出 60 元预算内的可行动作，例如先检查库存并列缺项。

两组分别记追问次数。改案时没有提到某项状态，可以用读书会的续问检查能否接回原记录。分别记改案时主动汇报了什么、续问时还能不能找回。材料不足保留为未观察。固定材料的对照和七天自然使用各按实际结果登记。 [配对评分与脱敏方式](https://github.com/Fangx-AI/awesome-xiaodou/blob/codex/s0-pilot/docs/field-tests/pilot-observer.md#普通小豆和皇帝模式配对评分)

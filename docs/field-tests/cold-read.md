# 小豆页面冷读

如果你第一次看到这个项目，欢迎花几分钟看看页面哪里好懂、哪里容易卡住。浏览器就能参加。

1. [打开这轮候选页面](https://github.com/Fangx-AI/awesome-xiaodou/blob/codex/s0-pilot/README.md)。照你平时的方式阅读，记下你第一次想点的位置。可以点一次确认它是否如你预期。
2. 用自己的话回答四件事：你觉得它是什么？在哪里用？想试一次会从哪里开始？如果涉及提醒或发消息，你觉得谁来决定是否执行？
3. 把你第一次想点的位置和没看懂的字句一起告诉观察者。有观察者在场时，让对方按[观察方法](pilot-observer.md#冷读-12-人)记录。

# 带自己的目标用小豆试七天

选一件你本来就想做的事，比如练一次英语开场、读两页书，或把下周要办的事排好。

## 今天开局

1. 打开[小豆独立 App](../install.md#下载和开通)，从[通用开局](../../README.md#一句话在小豆里开始)或[30 个计划](../../skills/xiaodou-skill/references/life-plans/README.md#选一个你想做的计划)复制一份，加上你的目标，一起发到新对话。观察者给了固定开局链接时，就用那一份。
2. 回答小豆需要了解的问题，和它定一个你能判断是否做完的第一步。比如「练一遍会议开场，记下卡住的词」。
3. 发出开局消息后，可以[在 GitHub 自愿登记][trial-form]。登记后收藏原帖，方便回来留言。有观察者时，可以直接告诉观察者你已开局。

## 做完就回报

在小豆原对话里告诉它做到哪里。条件变了，就说哪一项变了、哪些已经做完，再看看小豆排的新一步能不能照做。

如果登记过，**第一步做完当天就可以回原帖留言**。到第七天还在做或卡住了，也欢迎回来留一次结果。可以把下面三行复制到原帖，或直接发给观察者。

```text
我定的第一步：
做到哪了（全部完成／做了一部分／还没做）：
全部完成是哪一天（如有）：
```

如果计划变过，可以再写一句「什么变了、小豆保留了哪些已完成的事、下一步改成了什么」。

## 分享范围由你决定

GitHub 登记和留言会公开显示你的账号。用「英语」「练习开场一次」这类概括就够了。请省略姓名、病史、体重、学校、公司、邀请码和对话截图。 [App 兼容与实测状态](../compatibility.md)

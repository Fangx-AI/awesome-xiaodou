# 带自己的目标用小豆试七天

选一件你本来就想做的事，比如练一次英语开场、读两页书，或把下周要办的事排好。

## 今天开局

1. 打开[小豆独立 App](../install.md#下载和开通)。从[五个可直接发的场景](../share-cards.md)选一个，或用[通用开局](../../README.md#一句话在小豆里开始)填自己的目标。也可以在[30 个计划](../../skills/xiaodou-skill/references/life-plans/README.md#选一个你想做的计划)里按具体目标挑一条开局。把选好的开局整段发到新对话。观察者给了固定链接时，直接用那个链接里的代码块。
2. 回答小豆需要了解的问题，和它定一个你能判断是否做完的第一步。比如「练一遍会议开场，记下卡住的词」。
3. 发出开局消息后，可以[在 GitHub 自愿登记][trial-form]。填开局日期即可，找得到版本或已经有进展时可以顺手补上。登记后收藏原帖，方便回来留言。有观察者时，直接告诉对方你已开局即可。

## 做完就回报

在小豆原对话里告诉它做到哪里。条件变了，就说哪一项变了、哪些已经做完，再看看小豆排的新一步能不能照做。

做到一半也可以回报。比如原先约好「发出邮件」，现在可以说「邮件草稿写好了，还没发」。这样小豆就能从检查草稿或确认发送接着办。

如果计划一直没开始，可以回原对话说「第一步还没开始，我卡在……」。知道原因就直接说，例如「资料打不开」或「这两天都没空」。

**做完当天就可以回报。** 登记过就在原帖留言，第一次回报可以[用同一张表登记和填结果][trial-form]，有观察者也可以直接告诉对方。第七天还没做完，照实说做到哪里就行。

```text
第一步：
进展（哪天做完／做到哪了／卡在哪）：
改计划（如有）：
```

比如「第一步是练一遍开场。我在 2026-11-24 练完了。周四没空，小豆保留了这一遍，把下次练习挪到周六。」还在立案也可以写「还没有定出第一步」。

## 分享范围由你决定

# 用小豆办完一件自己的事

想练英语、开始阅读，或把一周的计划排顺？选一件你本来就想做的事，用小豆走到第一个看得见的结果。

还没进入小豆独立 App？先看[下载和开通](../install.md#下载和开通)。

## 今天开局

1. 选[通用开局](../../README.md#一句话在小豆里开始)或[对应的生活计划分类](../../skills/xiaodou-skill/references/life-plans/README.md#选一个你想做的计划)。复制一份，在末尾加你的真实目标和最近能用的时间，发到小豆独立 App 的新对话。
2. 看小豆给的第一步。月计划可以先回答它的问题。把第一步定成自己能判断是否做完的动作，比如「读一遍会议开场，记下卡住的词」。
3. 实际发出开局消息后，可以[在 GitHub 自愿登记][trial-form]，填写日期、设备和目标类别。有观察者时也可以直接告诉观察者。

有观察者发来的固定版本链接时，从该链接复制开局。登记时可以附上实际用的链接，方便核对版本。

如果你是看了一张分享卡才想试，登记时可以选是哪一张。

## 有结果就回到原对话

做完后可以直接说「我做完了这一步」。只做了一部分，就说做到哪里，还差什么。日程变了，告诉小豆哪一项变了、哪些已经做完，再看改后的下一步能不能照做。

如果登记过，到第七天请在原帖追加一次结果，做到和没做到都欢迎回报。有观察者时可直接把结果告诉观察者。

```text
原先定的第一步：
做到哪了（全部完成／做了一部分／还没做）：
第一步全部完成的日期（如有）：
什么变了（选填）：
小豆保留了哪些进度，改成了什么下一步（选填）：
```

## 分享范围由你决定

GitHub 登记会用你的 GitHub 账号公开显示。只写愿意公开的内容，例如「英语」「练习开场一次」。请省略真实身份、病史、体重、学校名单、公司名和对话截图。用虚构素材检查改案或提醒，可以走[固定的真机演练](pilot-s0.md)。

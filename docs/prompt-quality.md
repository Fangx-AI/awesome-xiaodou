# 用一个真实场景试提示词

从下面挑一条，在小豆新对话分别试一句普通提问与完整提示词，比较输出是否符合「怎么看成了」。有连接器的任务先用测试数据。只记录自己看到的结果。

## 先测两条主路径

普通小豆与 Skill 分开新建对话，使用相同的输入、资料、账号权限和 App 版本。记录首次追问次数、任务是否实际完成，以及改变条件后是否保留进展。开局测试可先用[首页指令](../README.md#一句话在小豆里开始)，再用完整版复跑并分别记结果。

- **减肥 H01**：[四轮演示](weight-first-week.md)提供固定菜单和相同的加班记录，用同一组输入比较两种回答。
- **截图日历 11**：先发一张脱敏截图或逐字转录，内容从「周三三点」改成「周四四点」，但不给原消息日期。检查是否先问日期。确认日期后，用测试日历核对执行结果。

若缺少手机、测试账号、授权或回执，对应项保留「未测」或「权限受限」。同样的输入在不同版本的结果分开记录。 [真机结果](field-tests/README.md)

| 场景 | 测试输入 | 怎么看成了 |
| --- | --- | --- |
| [皇帝模拟器](../prompts/emperor-simulator.md) | 「我想月底前剪出第一条视频，今晚只有 15 分钟。」接着说「选了题，只找到两段素材」和「我想换个对话」。 | 首轮只给一个能在 15 分钟内开始的动作，后续按已有进展给下一步，换对话时给可复制摘要。 |
| [皇帝模拟器：外部操作](../prompts/emperor-simulator.md) | 「我想约同事明天开会，先帮我写邀请。」看完草稿后说「方案没问题」。 | 直接给出草稿，待明确确认具体收件人和动作后才尝试发送。 |
| [皇帝模拟器：分流和续接](../prompts/emperor-simulator.md) | 先问「早朝是什么意思」，再说「月底剪成片，每周有三小时」，随后改成「这周只剩周日半小时，片头已经剪好」。 | 问答直接回答。复杂目标核对约束。改计划时保留已剪好的片头，只调整后续工作。 |
| [皇帝模拟器：执行结果未确认](../prompts/emperor-simulator.md) | 用测试账号确认写入日历，模拟连接器超时，再说「那再试一次」。 | 先核对原日历是否已写入，结果未知时明确说明，避免重复写入。 |
| [一个月减肥计划](../prompts/41-weight-plan.md) | 成年人，工作日常吃外卖，只有周二和周四各 25 分钟。第 7 天反馈周四加班没做成。 | 第一周排进实际空档，有点得到的外卖和忙碌备选。复盘后改下一周的安排。 |
| [朕要减肥：一句话开局](../prompts/41-weight-plan.md) | 在皇帝模拟器里说「朕想减肥，午饭只能点外卖。今天先怎么吃？」随后说「今天加班，没走路」。 | 首轮给一餐或今天的一步。漏做后允许改时间或休息。明确要求四周计划时才展开。 |
| [收藏找餐厅](../playbooks/09-saved-restaurants.md) | 收藏中两家分店同名，一家只有店名，预算人均 100 元。 | 地址和视频能对应。未知价、无法确定的分店有标注。没权限时可以改用我发的链接。 |
| [截图记日历](../playbooks/11-screenshot-calendar.md) | 先说「周三 3 点」，后改「周四 4 点」，截图没有消息日期。 | 识别最后约定，问清是哪一天，先给预览。确认后才尝试添加。 |
| [飞书周报](../playbooks/36-weekly-report.md) | 一条已交付、两条重复进展、一项只有意向且无负责人。 | 合并重复条目，已交付有来源，意向和未知负责人保留为待定。 |
| [行业早报](../playbooks/07-daily-brief.md) | 同一公告有两篇转载，昨天只有这一件实质更新。 | 只报一次，优先给原链接，说明为什么值得看。 |

# 朕要减肥：从第一顿外卖到第七天

这是一组虚构演示，用来说明应该怎样开始、记录和调整。实际结果在[真机试用登记](field-tests/README.md)。

| 时刻 | 你怎么说 | 小豆应该帮到哪一步 |
| --- | --- | --- |
| 第一次 | 「我成年，午饭只能点外卖。常点店有鸡肉饭、青菜、炸鸡套餐。今天怎么选？」 | 从现有菜单给一个组合，例如鸡肉饭配青菜。没有菜单时只请我发菜单或列几个选项。 |
| 吃完 | 「午饭点了鸡肉饭和青菜，下午没有饿。」 | 只记用户确认的点单和主观感受，不把计划里其他几天算作完成。 |
| 有变化 | 「今天加班，散步没做。」 | 保留午饭记录，散步标为未完成或改期。给一个现实的备选，让用户选是否采用。 |
| 第七天 | 「我只记了三天，两次按计划点外卖，一次加班。下周怎样安排？」 | 说清只有三天记录。保留已试过的组合，下周只调一个动作，例如把散步放进一个通常空着的时间段。 |

平时一句「今天我做了什么，哪里卡住」就够。想要完整安排时说「给朕排四周」。换对话可以先说「把目标、这周做过的和下一步整理成续聊摘要」。

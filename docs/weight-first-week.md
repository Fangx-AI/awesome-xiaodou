# 减肥计划怎么制定

在小豆里说 **「帮我制定一个减肥计划。」** 小豆先了解你的情况，再给适合你执行的方案。你也可以说想以运动为主、想改善饮食，或已经有计划但做不下去。

| 谁来做 | 帮你做什么 |
| --- | --- |
| **中书省** | 了解目标、饮食习惯、运动基础、可用时间，以及会影响方案的身体情况。 |
| **门下省** | 核对目标和强度是否现实。想用数字管理、资料也齐全时，再考虑估算热量。 |
| **尚书省** | 交付阶段路线和首周安排，写清哪天做什么、怎样算完成。实际做一周后，再和你一起调整。 |

### 不想报体重，也可以开始

例如，你想少喝甜饮，周二和周六各有一段时间能散步。首周可以先选两次午餐把甜饮换成水，再把散步排进这两个空档。如果哪天走不了，回报是哪一天，已做过的照常计入。第 7 天看看甜饮换了几次、散步做了几次，选一项保持或调整。

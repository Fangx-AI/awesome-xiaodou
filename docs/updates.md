# 小豆 Skill 更新记录

## v1.3.1

- 皇帝模拟器默认用普通聊天推进事项。三省六部按需检查和分工，默认只回一个下一步。古风、朝议和进度存档可按需开启。

## v1.3.0

- 新增[小豆皇帝模拟器](../prompts/emperor-simulator.md)。以三省六部分工管理个人目标，从下旨、审议和派活走到早晚复盘。可以单独粘贴，也可以从短版或完整技能包调用。

## v1.2.0

- 更新收藏找餐厅、截图记日历、飞书周报和行业早报四条指令。
- 新增[提示词出处](../skills/xiaodou-skill/references/prompt-sources.md)、[试用案例](prompt-quality.md)和结果反馈表单。

## v1.1.1

- H01 更新为[一个月减肥计划](../prompts/41-weight-plan.md)。提供四周路线图、按实际作息安排的首周行动表、忙碌时的替代做法和每周复盘。

## 2026-11-27 · v1.1.0

- 新增[确认后发送测试邮件](../playbooks/41-mail-confirm-send.md)。核对收件人和内容，确认后发送，再检查收件箱。
- 新增[筛选高铁并准备待支付订单](../playbooks/42-rail-order-preview.md)。按预算和时间窗查票，停在待支付，重试前先查订单。
- 更新[减肥计划](../prompts/41-weight-plan.md)。在用户主动要求时参考已授权的活动与睡眠记录，缺失时可以手填。
- 提供[短版 8 条](../prompts/xiaodou-quick-pack.txt)和[完整版 43 条](../prompts/xiaodou-paste-pack.txt)，同步更新技能 ZIP。

邮件和高铁依据 [Appstoy 作者实测](https://appstoy.com/1966.html)，健康记录的场景依据[每经记者实测](https://m.nbd.com.cn/articles/2026-11-26/4659127.html)。

## 2026-11-25 · v1.0.0

首版发布 41 条提示词，提供可粘贴文本及 Agent Skills ZIP。

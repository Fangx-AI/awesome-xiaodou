# 筛选高铁并准备待支付订单

[返回玩法目录](../docs/catalog.md) · [作者实测](https://appstoy.com/1966.html)

Ricky 经高铁管家查到二等座选项，重试后创建订单，页面停在待支付。

## 可复制指令

```text
查 [日期] 从 [出发城市] 到 [到达城市] 的高铁二等座。我希望 [时间窗] 出发，预算 [金额] 元。列出最多三趟，包含车站、到达时间、价格和查询时间。我选定后，再在已授权的连接器里准备订单并停在待支付。若创建报错，先查有没有已存在的同车次订单，避免重复建单。
```

## 核对结果

核对车站、日期、价格、乘车人和订单状态。支付与出票需分别核对。
